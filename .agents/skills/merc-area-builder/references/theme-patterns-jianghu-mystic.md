# Theme Patterns: Jianghu And Mystic

這份參考檔提供 `江湖風` 與 `仙俠風` 的 area 題材模板。

## 模板一：江湖風

適用情境：

- 城郊客棧
- 山道與古橋
- 幫派據點
- 門派外圍
- 市集、鏢局、茶棚、破廟

玩家感受：

- 人情、傳聞、試探、俠義與算計並存

地景與房間母型：

- 茶攤岔路口
- 山道石階
- 客棧前院
- 破廟偏殿
- 鏢局後場
- 河邊渡頭
- 林間練武空地
- 隱蔽的會面亭
- 掛滿懸賞的木牌處

描述語氣：

- 多用江湖傳言、刀客、行腳商、俠士、腳印、酒氣、雨幕、斗笠、舊匾、暗號
- 讓玩家感覺每個角落都可能藏故事、恩怨或機緣

NPC 類型：

- 說書老人
- 失意鏢師
- 浪人劍客
- 神祕遊醫
- 門派外門弟子
- 販賣消息的店小二
- 行蹤詭祕的黑衣客

可直接採用的三國 / 演義江湖化角色例：

- 隱居高人：水鏡先生、左慈、于吉
- 遊歷豪傑：趙雲、太史慈、馬超、甘寧
- 傳聞核心人物：貂蟬、呂布、孔明、周瑜
- 可作奇人異士或事件名號：臥龍、鳳雛、江東美周郎、燕人張翼德

武俠感安全轉譯例：

- 不直接寫特定作品角色名，改寫為：塞外刀客、古墓傳人、白衣劍客、醉酒老丐、黑木教使、華山老宿、雪山怪客
- 不直接寫特定門派名，改寫為：西嶽劍宗、北地丐盟、黑衣神教、古墓別院、少室禪門、南嶺藥宗
- 不直接寫特定招式名，改寫為：落英掌、追風劍訣、游龍步、寒魄指、裂碑掌、回風拂柳劍
- 若想做古龍感人物，可優先使用：寡言劍客、病容謀士、冷面刀客、落魄名捕、風塵歌姬、神祕莊主、黑衣刺客、帶笑的帳房先生
- 若想做古龍感場景，可優先使用：月下長街、寂靜酒肆、荒園小樓、風雪客棧、斷橋石亭、深巷賭坊、空庭花樹、藏刃書房
- 若想做古龍感互動與任務，可優先使用：赴一場約戰、查名榜真偽、追查買凶線索、在酒館流言中辨認真兇、保護證人過夜、尋找失落名器

任務 / 事件鉤子：

- 打聽失鏢下落
- 替人送信
- 替客棧解圍
- 追查夜間黑衣人
- 尋找失落秘笈殘頁
- 協調門派與地方糾紛

技能 / 道具 / 裝備母型：

- 技能：踏影步、聽風辨位、破招、凝息、借力打力、快劍
- 道具：殘頁秘笈、酒葫蘆、鏢旗、舊玉佩、黑市口令紙條
- 裝備：青鋒劍、短匕、斗笠、布袍、護腕、輕靴

三國風可直接落地的命名例：

- 武功 / 技能：七探盤蛇、錦帆夜渡、飛將摘星、連環巧計、破陣長歌
- 道具：孔明錦囊、赤兔馬鐙、錦帆鈴、古戰場殘簡
- 裝備：子龍戰袍、飛將護腕、江東羽披、白羽綸巾

`#Enquire` 建議詞：

- 客棧
- 茶棚
- 鏢局
- 渡口
- 破廟
- 懸賞

`#Keyword` 建議物件：

- 牌匾
- 酒罈
- 懸賞榜
- 斗笠
- 殘頁
- 暗門

避免事項：

- 不要讓所有 NPC 都說成一樣的江湖黑話；至少分出豪爽、冷淡、神祕、世故幾種口吻

## 模板二：仙俠風

適用情境：

- 地下水道
- 洞窟深處
- 古墓、封印地、濕地、水脈
- 詭異森林
- 失落祭壇或異象區

玩家感受：

- 不安、未知、潮濕、詭譎、探索風險與祕密獎勵並存

地景與房間母型：

- 滴水迴廊
- 被青苔覆蓋的石室
- 半沒入水中的祭壇
- 藏著低語的裂隙
- 佈滿骨片的窄道
- 泛著幽光的泉眼
- 封印石門前廳
- 積水岔路
- 地脈翻湧的洞腹

描述語氣：

- 多用潮氣、腐木、低語、霧氣、微光、殘痕、異香、陰影、水聲、寒意、封印、脈動
- 讓玩家從文字就知道這裡不只是打怪區，也是可能藏事件與秘密出口的地方

NPC / 生物類型：

- 守封殘魂
- 迷途探子
- 水妖
- 異化野獸
- 古老守陵者
- 被污染的修行者
- 低語引路的幽影

可直接採用的三國異聞角色例：

- 殘魂 / 幻影：董卓亡魂、呂布戰魂、袁術怨靈
- 方士 / 異人：左慈、于吉、南華老仙系統下的隱士角色
- 守陵 / 守藏者：漢室守陵人、銅雀遺藏守衛、失落軍府殘兵

可借鏡的仙俠母型：

- 仙劍感：宿命同伴、靈珠或異寶、鎖妖封印、古井與水脈、女媧 / 上古遺民型神話殘響、柔美與哀傷並存的場景
- 軒轅劍感：上古神器、遺跡文明、機關迷城、神州裂變、歷史與神話交纏、穿梭亂世時遇到的異界遺痕
- 共通可轉譯元素：封印塔、失衡地脈、古神祭壇、夢境回廊、妖霧沼澤、遺民石窟、機關石門、靈獸鎮守區

任務 / 事件鉤子：

- 調查失蹤巡兵
- 尋回被吞沒的信物
- 破解祭壇封印
- 追查水脈異變
- 封堵裂口中的妖氣
- 救出被困的探路者

技能 / 道具 / 裝備母型：

- 技能：鎮煞、聽潮、探脈、攝魂目、破瘴、靈息護體
- 道具：封符、殘破石片、潮濕卷軸、夜明珠、鎮水銅釘
- 裝備：避水披、符紋護腕、鎮邪短刀、陰鐵戒、護心鏡

三國風可直接落地的命名例：

- 武功 / 技能：七星鎮魄、八陣鎖脈、青囊驅瘴、將星護體、問卜觀氣
- 道具：孔明石陣殘圖、青囊遺卷、銅雀秘鑰、辟邪符簡
- 裝備：羽扇法衣、鎮煞冠、星紋護符、玄甲鎮心鏡

`#Enquire` 建議詞：

- 地下入口
- 水道
- 洞窟
- 祭壇
- 封印
- 裂隙

`#Keyword` 建議物件：

- 裂縫
- 石門
- 水痕
- 符文
- 祭壇
- 枯骨

避免事項：

- 不要只寫抽象形容詞；每個房間至少要有一個可視覺化實體
- 不要只剩空泛神秘感；要落到具體的封印物、石像、裂隙、水池、機關、壁畫、祭壇、枯骨、靈火等實體

## 穩定混搭

- `江湖風 + 仙俠風`：客棧傳聞通往古墓、門派禁地、水洞秘寶
- `軍旅風 + 仙俠風`：前線水脈異變、地下軍事暗道、封印哨站
- `探險遺跡風 + 仙俠風`：上古遺跡、機關祭壇、神器碎片線

# Theme Patterns: Civic And Military

這份參考檔提供 `歷史城市風` 與 `軍旅風` 的 area 題材模板。

## 模板一：軍旅風

適用情境：

- 主城外郊
- 邊關官道
- 軍營、哨站、糧道、關隘
- 國家勢力邊界、巡邏地帶、戰備前線

玩家感受：

- 紀律、壓力、戒備、秩序中的危機

地景與房間母型：

- 城門外軍道
- 木柵哨口
- 巡邏交會點
- 臨時糧車集結地
- 瞭望土坡
- 操練場邊帳
- 軍械堆放棚
- 受損的拒馬陣
- 夜巡營火區

描述語氣：

- 多用風沙、鐵甲、旌旗、戰馬、號角、夜哨、軍令、塵土、蹄痕、刀痕
- 強調視線、警戒、隊列、調度、補給線、可疑動靜

NPC 類型：

- 守門校尉
- 疲憊斥候
- 運糧兵
- 老軍匠
- 軍醫
- 軍法官
- 被徵召的鄉勇
- 可疑的敵國細作

可直接採用的三國人名範例：

- 鎮守型 NPC：關羽、張飛、趙雲、張遼、徐晃
- 謀士 / 指揮型 NPC：諸葛亮、司馬懿、荀彧、周瑜、郭嘉
- 權臣 / 軍閥型 NPC：曹操、董卓、袁紹、孫權、劉備
- 地方軍政角色：都尉、校尉、偏將、牙門將、主簿、軍司馬

任務 / 事件鉤子：

- 護送軍糧
- 傳遞軍令
- 偵查異常足跡
- 清除夜襲伏兵
- 修復損毀柵欄
- 協助盤查可疑商旅

技能 / 道具 / 裝備母型：

- 技能：槍陣、喝破、戰意、斥候步、守勢、弓騎術
- 道具：軍令牌、斥候哨、染血軍報、粗布糧袋
- 裝備：制式鐵甲、護臂、長槍、戰弓、校尉披風

三國風可直接落地的命名例：

- 武功 / 技能：青龍偃月勢、常山槍路、虎牢喝陣、八門軍略、白馬突襲
- 道具：丞相軍令、玄德手書、虎牢關軍報、羽林虎符
- 裝備：雁翎甲、虎頭湛金槍、烏騅韁繩、都亭侯戰袍

`#Enquire` 建議詞：

- 軍營
- 哨站
- 校場
- 軍醫
- 軍需
- 城門

`#Keyword` 建議物件：

- 拒馬
- 軍旗
- 糧車
- 望樓
- 號角
- 軍令

避免事項：

- 不要讓軍旅區突然塞入過度輕佻的江湖黑店或仙氣濃厚的秘境房間，除非有明確轉場節點

## 模板二：歷史城市風

適用情境：

- 主城本體
- 城門內外
- 市集、官府、碼頭、商行、民宅區
- 有明顯政權秩序與生活流動的區域

玩家感受：

- 城市活著、官民共存、地方風貌明確、不是只有戰鬥節點

地景與房間母型：

- 城門口
- 熙攘市集
- 官府前庭
- 倉廩區
- 碼頭木棧道
- 商行街
- 酒館內堂
- 巷口民宅區
- 書肆與告示牆
- 城牆下的巡邏道

NPC 類型：

- 商人
- 官吏
- 城衛兵
- 書生
- 船夫
- 掌櫃
- 百姓
- 流民
- 稅吏
- 街頭小販

任務 / 事件鉤子：

- 送官文
- 協助盤查商隊
- 查明失竊案
- 替碼頭調解糾紛
- 護送外地商旅進城
- 幫酒館尋找失聯供貨人
- 追查城中流言來源
- 幫官府張貼告示

物件 / 線索模板：

- 城門告示
- 商行招牌
- 倉庫門牌
- 官府公文箱
- 燈籠
- 木牌路標
- 市集貨攤
- 船繩
- 帳冊
- 稅單

`#Enquire` 建議詞：

- 官府
- 市集
- 商行
- 碼頭
- 酒館
- 城門

`#Keyword` 建議物件：

- 告示
- 帳冊
- 路牌
- 招牌
- 稅單
- 船繩

避免事項：

- 不要把城市區寫成只有店名清單；至少要有地方秩序、街區用途與民生壓力

## 穩定混搭

- `歷史城市風 + 軍旅風`：戰時都城、軍政壓力、盤查與戒嚴
- `軍旅風 + 江湖風`：邊城鏢局、軍鎮黑市、退伍老兵與遊俠交錯的外城

# Theme World Allocation

這份參考檔處理世界級題材配置，而不是單一 area 的房間細節。

## 六大題材

- `軍旅風`
- `江湖風`
- `仙俠風`
- `歷史城市風`
- `詭異民俗風`
- `探險遺跡風`

## 世界規劃原則

- 先讓題材分布平均，再做局部深化
- 先建立世界級題材池，再往州郡、主城、郊外、秘境與 cluster 落地
- 單一 area 先確認自己在整張地圖中的主題角色，不要每區都做成同一種氣味

## 建議第一輪占比

- `軍旅風`：20%
- `江湖風`：20%
- `仙俠風`：20%
- `歷史城市風`：20%
- `詭異民俗風`：10%
- `探險遺跡風`：10%

## 世界級檢查點

當 area rebuild 屬於世界級規劃時，先檢查：

- 哪些題材已過多
- 哪些題材仍不足
- 這個新 area 是在補空白，還是在強化既有優勢

每類題材至少都應具備：

1. 場景模板
2. NPC 模板
3. 任務模板
4. 物件模板
5. 區域事件模板
6. 傳聞或 `#Enquire` 線索模板

- `洛陽`：`歷史城市風` 主、`江湖風` 輔

- `江東`：`江湖風` 主、`歷史城市風` 輔
- `益州`：`仙俠風` 主、`探險遺跡風` 輔
- `漢中`：`軍旅風` 主、`仙俠風` 輔
- `西涼`：`軍旅風` 主、`探險遺跡風` 輔
- `南中 / 南蠻`：`探險遺跡風` 主、`詭異民俗風` 輔

把這份分區表當 heuristic，不是硬規定；若 repo 既有 area 已形成明確性格，優先順著既有風貌擴寫。

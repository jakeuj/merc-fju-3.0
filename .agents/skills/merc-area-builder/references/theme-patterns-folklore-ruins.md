# Theme Patterns: Folklore And Ruins

這份參考檔提供 `詭異民俗風` 與 `探險遺跡風` 的 area 題材模板。

## 模板一：詭異民俗風

適用情境：

- 荒村
- 祠堂
- 古井
- 山神廟
- 野林與夜路

玩家感受：

- 怪談、鄉野傳說、不祥、真假難辨的人鬼妖事

地景與房間母型：

- 荒村入口
- 古井旁空地
- 破敗祠堂
- 山神廟前
- 老樹下泥地
- 起霧田埂
- 夜半無人的巷尾
- 狐火閃爍的林邊
- 無人看守的義莊外
- 斷裂石碑前

NPC / 生物類型：

- 神情恍惚的村民
- 祠祝
- 流浪道士
- 狐妖
- 冤魂
- 夜哭孩童的幻影
- 守廟老者
- 借宿旅人
- 含冤亡者
- 山精野怪

任務 / 事件鉤子：

- 調查村民失蹤案
- 封住夜裡哭聲來源
- 尋找被井中吞沒的信物
- 安撫被驚擾的山神祭祀
- 查明狐妖是否真是元凶
- 替村民護送驅邪符物
- 調查祠堂血跡來源
- 找出夜路指錯方向的幽影

物件 / 線索模板：

- 古井
- 祭桌
- 紙錢
- 木偶
- 石碑
- 香爐
- 祈願牌
- 殘破神像
- 鈴鐺
- 油紙燈籠

`#Enquire` 建議詞：

- 祠堂
- 古井
- 山神廟
- 義莊
- 荒村
- 驅邪

`#Keyword` 建議物件：

- 紅繩
- 井口
- 紙錢
- 神像
- 石碑
- 鈴鐺

避免事項：

- 真相不一定要真有鬼，但一定要有可追查的故事，不要只靠音效形容詞撐場

## 模板二：探險遺跡風

適用情境：

- 地宮
- 失落古城
- 地下迷宮
- 廢都
- 遠古戰場遺址

玩家感受：

- 想往更深處走的探索衝動、危機感、發現感、文明殘響

地景與房間母型：

- 崩塌石階入口
- 地下迷宮轉角
- 失落古城中庭
- 廢棄神殿長廊
- 機關橋前室
- 守護獸棲地
- 沉沒寶庫外環
- 石像排列的封閉大廳
- 地圖碎片藏匿處
- 遠古戰場遺址

NPC / 生物類型：

- 探寶客
- 地圖商人
- 守關機關獸
- 失散傭兵
- 遺跡守衛殘兵
- 盜墓者
- 古文明殘影
- 陷阱設計者後裔
- 地下拾荒者
- 遺跡研究者

任務 / 事件鉤子：

- 收集地圖碎片
- 啟動失效機關橋
- 救出迷路探險隊
- 破解古代防衛陣列
- 打開被封住的寶庫
- 確認遺跡深處是否有異象
- 取回古文書
- 擊敗甦醒的守護者

物件 / 線索模板：

- 齒輪
- 石盤
- 銅鎖
- 控制桿
- 機關槽
- 地圖碎片
- 石像
- 古箱
- 導軌
- 鑰匙石片

`#Enquire` 建議詞：

- 遺跡
- 地宮
- 寶庫
- 機關橋
- 探寶
- 古城

`#Keyword` 建議物件：

- 石盤
- 齒輪
- 石像
- 古箱
- 導軌
- 石片

避免事項：

- 不要只做線性洞窟；要保留探索節奏、地標、深度回報與秘密點

## 穩定混搭

- `詭異民俗風 + 江湖風`：荒村疑案、夜路傳聞、破廟奇遇
- `探險遺跡風 + 軍旅風`：古戰場遺址、殘兵怨影、軍械秘庫

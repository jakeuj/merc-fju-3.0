# Area Theme Design Patterns

這份參考檔提供 `merc-area-builder` 在規劃新 AREA、補寫房間描述或擴充 NPC / 任務 / 技能 / 道具時可直接套用的題材模板。

用途：

- 幫 `map.md` prose 補出穩定的敘事語氣
- 幫 room cluster、`#Keyword`、`#Enquire`、NPC 與 quest hook 維持同一主題
- 幫 area 從只有拓樸骨架，提升成有帶入感、可持續擴寫的區域
- 幫世界級規劃維持題材分布平均，避免整張地圖只剩客棧、洞窟或軍營

原則：

- 優先採用「題材母型」，不要直接照抄外部作品固有名詞
- 先對齊 repo 既有世界、城市、國家、技能與 help 用語
- 題材模板是 flavor 與設計輔助，不是新的 source of truth
- `三國志`、`三國演義` 與其歷史人物、地名、官職、典故可視為本 skill 允許直接採用的題材來源；在不破壞 repo 既有設定的前提下，可直接使用如曹操、劉備、關羽、張飛、趙雲、諸葛亮、呂布、董卓等人物名稱來提升真實性與辨識度
- 對三國題材，允許直接採用陣營、戰役、名將、軍師、州郡、關隘與演義色彩濃厚的敘述方式；優先把它們落成 Merc-FJU 可互動的 NPC、事件、武功、裝備、任務與場景
- `幻想三國志`、金庸小說 / 遊戲衍生作、古龍小說、`仙劍奇俠傳`、`軒轅劍` 與其他近代作品仍以「題材母型 / 改寫致敬」為主；不要把受保護作品中的專有角色名、門派名、完整招式名、關鍵劇情橋段直接搬進 area
- 若想要做出強烈的金庸感，優先抽取下列母型後重新命名：名門正派與邪派對立、山巔論劍、藏經閣或石壁祕刻、奇遇高人、舊恩怨情仇、邊城客棧、古墓秘道、掌法 / 劍法 / 輕功 / 內功多路並存
- 若想要做出強烈的古龍感，優先抽取下列母型後重新命名：寂寥劍客、江湖名榜、冷峻殺手、詭譎陰謀、短促狠辣的對決、酒館流言、月夜決戰、朋友反目、名器與名劍、藏在笑語中的殺機
- 若想要做出強烈的仙俠感，優先抽取下列母型後重新命名：鎖妖塔 / 封印之地、上古遺跡、神器碎片、宿命輪迴、靈獸守關、古墓地宮、水月幻境、地脈異動、祭壇、幻術、失落古國、神魔餘痕、帶悲劇感的守護者
- 武俠題材可直接使用通用類型詞與公共領域風格詞，例如：掌門、少俠、俠女、長老、掌法、劍訣、輕功、內息、經脈、祕笈、山莊、劍塚、古墓、丐幫型流民組織、名門正宗、魔教型異端勢力；但避免直接寫成特定作品的唯一識別名稱

## 世界級題材配置

預設將三國 MUD 世界視為六大題材類型共同組成，而不是只有 `軍旅風`、`江湖風`、`仙俠風` 三類：

- `軍旅風`
- `江湖風`
- `仙俠風`
- `歷史城市風`
- `詭異民俗風`
- `探險遺跡風`

世界規劃原則：

- 先讓題材類型分布平均，再做局部深化
- 先建立世界級題材池，再往州郡、主城、郊外、秘境與 cluster 落地
- 若是單一 area 規劃，先確認它在整張地圖中的主題角色，不要把每區都做成同一種氣味

建議第一輪占比：

- `軍旅風`：20%
- `江湖風`：20%
- `仙俠風`：20%
- `歷史城市風`：20%
- `詭異民俗風`：10%
- `探險遺跡風`：10%

當 area/rebuild 屬於世界級規劃時，先主動檢查：

- 哪些題材已過多
- 哪些題材仍不足
- 這個新 area 是在補空白，還是在強化既有優勢

每一類題材至少都應具備這六種模板層：

1. 場景模板
2. NPC 模板
3. 任務模板
4. 物件模板
5. 區域事件模板
6. 傳聞或 `#Enquire` 線索模板

## 使用方式

當需求符合下列任一情境時，讀這份檔案：

- 新增 AREA，但目前只有 world links 與拓樸草圖，缺少風格與內容密度
- 房間彼此可走通，卻缺乏場景辨識度、NPC 個性與事件張力
- 想替同一區域建立一致的房間描述、敵人來源、掉落、服務點與支線語氣
- 想把區域做成明確主題，例如 `軍旅風`、`江湖風`、`仙俠風`
- 想替主城、郊外、荒村、遺跡與秘境做世界級題材分工
- 想評估某區在整張地圖中還缺哪一類題材

使用步驟：

1. 先決定 area 主題，只選一個主題當主骨架
2. 依主題挑選房間語氣、NPC 類型、任務鉤子、互動物件、技能與掉落母型
3. 若區域需要混搭，只允許一個主題為主、一個主題為輔，避免語氣失焦
4. 把主題訊號落到 `map.md` prose、`mapmd-json` labels/cluster、未來 `.roo` 的 `#Keyword` / `#Enquire`
5. 若是世界級規劃，再補一行「這區在六大題材中的定位」與「它在整張地圖中的缺口價值」

## 模板一：軍旅風

適用情境：

- 主城外郊
- 邊關官道
- 軍營、哨站、糧道、關隘
- 國家勢力邊界、巡邏地帶、戰備前線

玩家感受：

- 紀律、壓力、戒備、秩序中的危機

地景與房間母型：

- 城門外軍道
- 木柵哨口
- 巡邏交會點
- 臨時糧車集結地
- 瞭望土坡
- 操練場邊帳
- 軍械堆放棚
- 受損的拒馬陣
- 夜巡營火區

描述語氣：

- 多用風沙、鐵甲、旌旗、戰馬、號角、夜哨、軍令、塵土、蹄痕、刀痕
- 強調視線、警戒、隊列、調度、補給線、可疑動靜

NPC 類型：

- 守門校尉
- 疲憊斥候
- 運糧兵
- 老軍匠
- 軍醫
- 軍法官
- 被徵召的鄉勇
- 可疑的敵國細作

可直接採用的三國人名範例：

- 鎮守型 NPC：關羽、張飛、趙雲、張遼、徐晃
- 謀士 / 指揮型 NPC：諸葛亮、司馬懿、荀彧、周瑜、郭嘉
- 權臣 / 軍閥型 NPC：曹操、董卓、袁紹、孫權、劉備
- 地方軍政角色：都尉、校尉、偏將、牙門將、主簿、軍司馬

任務 / 事件鉤子：

- 護送軍糧
- 傳遞軍令
- 偵查異常足跡
- 清除夜襲伏兵
- 修復損毀柵欄
- 協助盤查可疑商旅

技能 / 道具 / 裝備母型：

- 技能：槍陣、喝破、戰意、斥候步、守勢、弓騎術
- 道具：軍令牌、斥候哨、染血軍報、粗布糧袋
- 裝備：制式鐵甲、護臂、長槍、戰弓、校尉披風

三國風可直接落地的命名例：

- 武功 / 技能：青龍偃月勢、常山槍路、虎牢喝陣、八門軍略、白馬突襲
- 道具：丞相軍令、玄德手書、虎牢關軍報、羽林虎符
- 裝備：雁翎甲、虎頭湛金槍、烏騅韁繩、都亭侯戰袍

`#Enquire` 建議詞：

- 軍營
- 哨站
- 校場
- 軍醫
- 軍需
- 城門

`#Keyword` 建議物件：

- 拒馬
- 軍旗
- 糧車
- 望樓
- 號角
- 軍令

避免事項：

- 不要讓軍旅區突然塞入過度輕佻的江湖黑店或仙氣濃厚的秘境房間，除非有明確轉場節點

## 模板二：江湖風

適用情境：

- 城郊客棧
- 山道與古橋
- 幫派據點
- 門派外圍
- 市集、鏢局、茶棚、破廟

玩家感受：

- 人情、傳聞、試探、俠義與算計並存

地景與房間母型：

- 茶攤岔路口
- 山道石階
- 客棧前院
- 破廟偏殿
- 鏢局後場
- 河邊渡頭
- 林間練武空地
- 隱蔽的會面亭
- 掛滿懸賞的木牌處

描述語氣：

- 多用江湖傳言、刀客、行腳商、俠士、腳印、酒氣、雨幕、斗笠、舊匾、暗號
- 讓玩家感覺每個角落都可能藏故事、恩怨或機緣

NPC 類型：

- 說書老人
- 失意鏢師
- 浪人劍客
- 神祕遊醫
- 門派外門弟子
- 販賣消息的店小二
- 行蹤詭祕的黑衣客

可直接採用的三國 / 演義江湖化角色例：

- 隱居高人：水鏡先生、左慈、于吉
- 遊歷豪傑：趙雲、太史慈、馬超、甘寧
- 傳聞核心人物：貂蟬、呂布、孔明、周瑜
- 可作奇人異士或事件名號：臥龍、鳳雛、江東美周郎、燕人張翼德

武俠感安全轉譯例：

- 不直接寫特定作品角色名，改寫為：塞外刀客、古墓傳人、白衣劍客、醉酒老丐、黑木教使、華山老宿、雪山怪客
- 不直接寫特定門派名，改寫為：西嶽劍宗、北地丐盟、黑衣神教、古墓別院、少室禪門、南嶺藥宗
- 不直接寫特定招式名，改寫為：落英掌、追風劍訣、游龍步、寒魄指、裂碑掌、回風拂柳劍
- 若想做古龍感人物，可優先使用：寡言劍客、病容謀士、冷面刀客、落魄名捕、風塵歌姬、神祕莊主、黑衣刺客、帶笑的帳房先生
- 若想做古龍感場景，可優先使用：月下長街、寂靜酒肆、荒園小樓、風雪客棧、斷橋石亭、深巷賭坊、空庭花樹、藏刃書房
- 若想做古龍感互動與任務，可優先使用：赴一場約戰、查名榜真偽、追查買凶線索、在酒館流言中辨認真兇、保護證人過夜、尋找失落名器

任務 / 事件鉤子：

- 打聽失鏢下落
- 替人送信
- 替客棧解圍
- 追查夜間黑衣人
- 尋找失落秘笈殘頁
- 協調門派與地方糾紛

技能 / 道具 / 裝備母型：

- 技能：踏影步、聽風辨位、破招、凝息、借力打力、快劍
- 道具：殘頁秘笈、酒葫蘆、鏢旗、舊玉佩、黑市口令紙條
- 裝備：青鋒劍、短匕、斗笠、布袍、護腕、輕靴

三國風可直接落地的命名例：

- 武功 / 技能：七探盤蛇、錦帆夜渡、飛將摘星、連環巧計、破陣長歌
- 道具：孔明錦囊、赤兔馬鐙、錦帆鈴、古戰場殘簡
- 裝備：子龍戰袍、飛將護腕、江東羽披、白羽綸巾

`#Enquire` 建議詞：

- 客棧
- 茶棚
- 鏢局
- 渡口
- 破廟
- 懸賞

`#Keyword` 建議物件：

- 牌匾
- 酒罈
- 懸賞榜
- 斗笠
- 殘頁
- 暗門

避免事項：

- 不要讓所有 NPC 都說成一樣的江湖黑話；至少分出豪爽、冷淡、神祕、世故幾種口吻

## 模板三：仙俠風

適用情境：

- 地下水道
- 洞窟深處
- 古墓、封印地、濕地、水脈
- 詭異森林
- 失落祭壇或異象區

玩家感受：

- 不安、未知、潮濕、詭譎、探索風險與祕密獎勵並存

地景與房間母型：

- 滴水迴廊
- 被青苔覆蓋的石室
- 半沒入水中的祭壇
- 藏著低語的裂隙
- 佈滿骨片的窄道
- 泛著幽光的泉眼
- 封印石門前廳
- 積水岔路
- 地脈翻湧的洞腹

描述語氣：

- 多用潮氣、腐木、低語、霧氣、微光、殘痕、異香、陰影、水聲、寒意、封印、脈動
- 讓玩家從文字就知道這裡不只是打怪區，也是可能藏事件與秘密出口的地方

NPC / 生物類型：

- 守封殘魂
- 迷途探子
- 水妖
- 異化野獸
- 古老守陵者
- 被污染的修行者
- 低語引路的幽影

可直接採用的三國異聞角色例：

- 殘魂 / 幻影：董卓亡魂、呂布戰魂、袁術怨靈
- 方士 / 異人：左慈、于吉、南華老仙系統下的隱士角色
- 守陵 / 守藏者：漢室守陵人、銅雀遺藏守衛、失落軍府殘兵

可借鏡的仙俠母型：

- 仙劍感：宿命同伴、靈珠或異寶、鎖妖封印、古井與水脈、女媧 / 上古遺民型神話殘響、柔美與哀傷並存的場景
- 軒轅劍感：上古神器、遺跡文明、機關迷城、神州裂變、歷史與神話交纏、穿梭亂世時遇到的異界遺痕
- 共通可轉譯元素：封印塔、失衡地脈、古神祭壇、夢境回廊、妖霧沼澤、遺民石窟、機關石門、靈獸鎮守區

任務 / 事件鉤子：

- 調查失蹤巡兵
- 尋回被吞沒的信物
- 破解祭壇封印
- 追查水脈異變
- 封堵裂口中的妖氣
- 救出被困的探路者

技能 / 道具 / 裝備母型：

- 技能：鎮煞、聽潮、探脈、攝魂目、破瘴、靈息護體
- 道具：封符、殘破石片、潮濕卷軸、夜明珠、鎮水銅釘
- 裝備：避水披、符紋護腕、鎮邪短刀、陰鐵戒、護心鏡

三國風可直接落地的命名例：

- 武功 / 技能：七星鎮魄、八陣鎖脈、青囊驅瘴、將星護體、問卜觀氣
- 道具：孔明石陣殘圖、青囊遺卷、銅雀秘鑰、辟邪符簡
- 裝備：羽扇法衣、鎮煞冠、星紋護符、玄甲鎮心鏡

仙俠感安全轉譯例：

- 人物：守塔少女、失憶祭司、古國遺民、封印看守人、半妖旅者、背負宿命的劍士、機關師、逐靈方士
- 生物：水魄、石魈、瘴靈、夢魘狐、鎮墓木偶、機關獸、地脈妖藤、殘缺神使
- 技能：御靈步、鎮魂訣、破瘴印、回夢咒、攝靈指、天衡劍氣、引星護元、辟邪符法
- 道具：靈珠碎片、古碑殘文、封印玉環、機關樞紐、祭壇石片、避瘴香囊、古劍殘鍔
- 裝備：流光法衣、鎮靈佩、機關護腕、月魄長靴、天工面甲、辟邪玉冠

仙俠風子模板：

### 子模板 A：水月靈境

適用情境：

- 湖畔秘境
- 水底洞府
- 靈泉周邊
- 霧中孤島

核心感受：

- 空靈、柔美、哀傷、若真若幻

代表場景：

- 倒映殘月的靈池
- 長滿青藤的水榭遺跡
- 霧氣瀰漫的石橋
- 靈獸守望的月井

常用元素：

- 水鏡
- 靈珠
- 月影
- 霧幕
- 靈狐
- 水魄

任務鉤子：

- 尋回失落靈珠
- 安撫受驚靈獸
- 調查水面異象
- 找出夢境與現世交疊的原因

### 子模板 B：古墓封印

適用情境：

- 皇陵地宮
- 失落祭壇
- 山腹墓道
- 鎮妖封印之所

核心感受：

- 肅穆、危險、壓迫、帶著被時間掩埋的秘密

代表場景：

- 刻滿符紋的石門
- 半毀的陪葬廊道
- 地底祭壇前廳
- 殘魂守著的封印核心

常用元素：

- 石棺
- 鎮符
- 枯骨
- 銅燈
- 封印柱
- 祭器

任務鉤子：

- 修補鬆動的封印
- 查明墓中怨氣來源
- 找回失落的鎮墓器
- 護送方士深入祭壇

## 混搭規則

允許的穩定混搭：

- 軍旅風 + 仙俠風：前線水脈異變、地下軍事暗道、封印哨站
- 江湖風 + 仙俠風：客棧傳聞通往古墓、門派禁地、水洞秘寶
- 軍旅風 + 江湖風：邊城鏢局、軍鎮黑市、退伍老兵與遊俠交錯的外城
- 歷史城市風 + 江湖風：主城黑市、商行與鏢局混合區、城內傳聞鏈
- 歷史城市風 + 軍旅風：戰時都城、軍政壓力、盤查與戒嚴
- 詭異民俗風 + 江湖風：荒村疑案、夜路傳聞、破廟奇遇
- 探險遺跡風 + 仙俠風：上古遺跡、機關祭壇、神器碎片線
- 探險遺跡風 + 軍旅風：古戰場遺址、殘兵怨影、軍械秘庫

混搭方法：

- 主題主色只選一個，另一個只用在支線、支房、少數 NPC 或特殊事件
- 描述詞庫以主題為主，輔題材只做局部點綴
- `#Enquire` 與服務節點要維持主題清晰，不要讓玩家問路時語義混亂

若主題核心就是三國：

- 可以直接使用演義人物、歷史官職、州郡地名與戰役典故
- 優先把知名人物放在高辨識度節點，例如城門守將、軍營主官、茶棚傳聞中心、秘境守關戰魂
- 若使用知名人物本名，房間描述、對話口吻、掉落物與任務線也要跟角色形象一致，不要只借名字

## 快速套用清單

當你要開始寫一個新 area 時，先補出這 8 件事：

1. 主題是什麼
2. 玩家第一眼會感受到什麼
3. 這區最典型的 3 種房間長相
4. 這區最常遇見的 3 類 NPC
5. 這區最合理的 2 到 4 條支線鉤子
6. 這區會掉什麼風格的物件或裝備
7. 玩家最可能 `enquire` 的地點或服務是什麼
8. 哪些物件要靠 `#Keyword` 提示玩家互動
9. 這區的代表性事件是什麼
10. 這區的秘密點或隱藏鉤子是什麼

## 與 map.md 的對接建議

在 `map.md` prose 中，至少補這些欄位：

- `Theme`: 主題模板名稱
- `Subtheme`: 子題材或輔助題材
- `Mood`: 玩家感受關鍵詞
- `Signature scenes`: 3 到 5 個代表場景
- `NPC factions or roles`: 主要 NPC 群像
- `Quest hooks`: 初版支線鉤子
- `Interaction cues`: 需要 `#Keyword` / `#Enquire` / `#Job` 的節點
- `Rumor seeds`: 傳聞與玩家可追查的線索
- `Local props`: 高辨識度實體物件
- `Secret node or hidden hook`: 秘密點、隱藏路徑或特殊發現

房間與 cluster 落地原則：

- 每個房間至少要有一個可視實體、一個氛圍線索、一個可能互動或延伸的點
- 每個重要 NPC 至少要有口吻、立場、記憶點台詞、或與區域事件的關聯
- 每個 area 至少要有一個安全點、一個服務型 NPC、一條任務線、一種代表性敵人、一個秘密點

若 area 要交給 scaffold script，記得：

- 主題說明留在 prose
- 拓樸、cluster、節點 metadata 留在 `mapmd-json`
- 不要把題材段落寫成會誤導 generator 的假 schema

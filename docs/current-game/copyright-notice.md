# Legacy 版權宣告

這頁整理 `document/COPYRIGHT` 的重點，方便在 GitHub Pages 上直接查閱。

- 相關上游授權文件另見：

## 核心背景

文件明確說明這個版本是由 `merc 2.2` 修改而來，因此版權一部分仍屬於 Diku / Merc。

同時它列出當時的 Merc-FJU 製作群成員與聯絡方式，並把 repo 中一批目錄視為這份配件版權宣告涵蓋的範圍。

## 文件列出的重點規則

1. 不可刪除或修改配件內任何版權宣告。
2. 若以這批配件建立公開遊戲，需事先通知 merc 與製作群。
3. 若只使用其中一部分，也必須保留版權宣告。
4. 公開遊戲需明確標示 Diku Merc 與「三國歪傳之降龍伏虎」字樣。
5. 釋出版本中的 area 不可直接原樣用於公開遊戲，`limbo` 除外。
6. 公開遊戲需包含 `help fju` 與 `credit`。
7. 允許自由修改與釋出，但不得涉及商業或不法行為。

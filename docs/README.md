# Docs Layout

- `docs/3yWebsite/` 是舊版遊戲介紹網站的鏡像與參考資料，供世界觀、命名、公告、地圖與歷史技能脈絡比對使用；預設不拿來登記目前 repo 新增或改寫後的正式 runtime 資料。
- `docs/current-game/` 用來記錄目前這個 repo 額外補上的開發者文件與機器可讀台帳，內容應明確標示它是對現行 `src/`、`skill/`、`area/`、`data/` 的補充說明，而不是舊站快照。
- GitHub Pages 入口預設放在 `docs/index.md`，`docs/current-game/` 是現行版本內容區；舊版站點則連到外部的 `https://3y.jakeuj.com/`。

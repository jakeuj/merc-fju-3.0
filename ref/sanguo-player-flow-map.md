
# 三國 MUD 玩家活動熱區圖 (Player Flow Map)

這張圖表示 **玩家活動熱區 (Player Flow)**，用來預測或設計玩家在世界中的活動分布。

## 設計目的

- 控制刷怪區密度
- 集中任務區域
- 規劃 PvP 或事件區
- 避免世界過於空曠

## 活動強度示例

| 區域 | 玩家活動強度 |
|---|---|
| 洛陽 | 95 |
| 龍渠丘陵 | 70 |
| 陳留 | 60 |
| 濮陽森林 | 55 |
| 官渡戰場 | 65 |
| 虎牢關 | 50 |
| 襄陽 | 80 |
| 江夏水域 | 75 |
| 雲夢大澤 | 78 |
| 建業 | 85 |
| 會稽山林 | 60 |
| 武陵山 | 68 |
| 南蠻叢林 | 52 |
| 上古遺跡 | 45 |

數值為相對強度 (0–100)，並不代表實際玩家數量，而是 **設計預期活躍程度**。

## 一般設計原則

| 區域類型 | 玩家活動 |
|---|---|
| 主城 (City) | 非常高 |
| 城郊 (Outskirts) | 高 |
| 野外 (Wild) | 中 |
| 副本 (Dungeon) | 中高 |
| 秘境 (Secret) | 低但集中 |

## 使用方式

開發時可搭配：

- World Map
- Room Density Map
- Area Cluster Map

一起調整世界節奏。

# 三國 MUD AREA Scaffold

本壓縮檔依 `world-graph.json` 自動生成 **130 個 AREA scaffold**。

結構：
```text
area/
  <node_id>/
    map.md
```

每個 `map.md` 已預填：
- 基本 metadata
- 與世界圖對應的 Connections
- Theme / Mood / Signature scenes
- NPC / Quest hooks / Interaction cues
- 備註與後續擴寫建議

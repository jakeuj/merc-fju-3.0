
# 三國 MUD 世界 Room Density Map

這張圖表示 **各重要 AREA 的房間密度 (Room Count)**。

設計目的：
- 控制玩家活動熱區
- 確保主城與探索區比例合理
- 避免某些區域過大或過空

## 設計原則

| 類型 | 建議房間數 |
|---|---|
| City | 80–150 |
| Outskirts | 30–60 |
| Wild | 50–100 |
| Fort | 40–80 |
| Dungeon | 60–120 |
| Secret | 20–60 |

## 世界整體規模估算

假設：

- 120 AREA
- 平均 25 rooms / 小區
- 大型區域 80–140 rooms

則世界規模：

≈ **2500 – 3500 rooms**

這與典型大型 MUD 世界相近。


# 三國 MUD Area Cluster Map

此文件展示 **Area → Cluster → Room 結構**，是大型 MUD 常用的世界分層設計方式。

設計層級：

World
→ Region
→ Area
→ Cluster
→ Room

這樣可以讓 120+ AREA 的世界在開發時保持可管理性。

# Cluster 設計規則

### City Area

通常包含：

```
城門
主街
市集
官府
居民區
特殊入口
```

### Outskirts Area

```
回城入口
官道
岔路
農田 / 林地
特殊事件點
```

### Wild Area

```
入口
主要探索區
地標
隱藏支線
```

### Fort Area

```
關前道
外寨
關門
關樓
軍營
```

### Dungeon Area

```
入口
主通道
支路
機關房
Boss 房
```

# 世界規模推算

如果你的世界是：

```
120 AREA
```

平均：

```
1 AREA ≈ 3–6 clusters
1 cluster ≈ 5–10 rooms
```

則世界規模會是：

```
120 AREA
≈ 400 clusters
≈ 2000–3500 rooms
```

這是 **典型大型 MUD 世界大小**。

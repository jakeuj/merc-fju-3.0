
# MUD World Map Editor PRO

A visual tool to design your MUD world graph.

Features:

✔ Drag & drop AREA nodes  
✔ Connect nodes with edges  
✔ Export world-graph.json  
✔ Export Mermaid world graph  
✔ Import existing world graph

Usage:

1. Open `index.html`
2. Add areas
3. Click **Connect Areas** and select two nodes
4. Export JSON

This integrates directly with:

- world builder
- map generator
- mudlet map tools
